# PlayMySong

**Learn songs. Play your way.**

PlayMySong is a guitar-learning project focused on helping players learn melodies through clear, interactive tablature.

## Initial product direction

- Start with single-note lead melodies.
- Display guitar tablature in a clear, readable format.
- Keep the first version focused on notes rather than chords or lyrics.
- Design the experience to work well on desktop and mobile.
- Begin with Bollywood and Indian songs, with a structure that can expand to other languages and genres.

## Planned experience

- Interactive guitar tab display
- Fretboard visualisation
- Tempo and playback controls
- Loopable practice sections
- Favourite songs
- A foundation for future fingerstyle arrangements

## Planned technology

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Lucide icons
- Web Audio API for playback
- Local storage and Progressive Web App support
- Vitest and Playwright for testing

## Project status

The repository is being bootstrapped. Features and implementation details will be added incrementally.

## Product principles

- Simple, focused learning experience
- Responsive and accessible interface
- Clean architecture and reusable components
- No subscription requirement in the planned product direction
